## KEY PATTERNS TO GRAFT

### 1. SKILL.md as Delivery Format
Every soul we sell is a SKILL.md file. The user downloads it, puts it in `~/.claude/skills/soul-name/`, and their AI becomes that soul. The file contains:
- Identity (name, archetype, voice)
- Skills (what the soul can do)
- Parameters (tunable dials)
- PLT score

### 2. Taste Skill's 3-Parameter System
Taste Skill has 3 adjustable parameters like an equalizer:
- DESIGN_VARIANCE (1-10): conventional → experimental
- MOTION_INTENSITY (1-10): subtle → kinetic
- VISUAL_DENSITY (1-10): airy → dense

**For soul guns:** Every gun should have 3 tunable parameters that change its behavior.

### 3. Impeccable's Anti-Slop Language
Impeccable (35.8k⭐) installs 23 commands to steer AI output: `polish`, `audit`, `critique`, `distill`, `animate`, `bolder`, `quieter`.

**For souls:** Every soul should have commands that let the user steer its behavior.

### 4. UI/UX Pro Max Auto Design System
88.7k⭐ skill auto-generates a complete design system from a project description. "Fintech dashboard" → chooses style, colors, typography automatically.

**For Soul Economy Hub:** The catalog should auto-tag items based on PLT scores, archetypes, and use cases.

## APPLIED TO SOUL ECONOMY HUB

The hub needs to work like the Claude Code skill marketplace:
1. Browse by category (soul, skill, pack, world, agent, book)
2. One-click download → `.zip` with SKILL.md + assets
3. User installs to their AI's skills folder
4. AI becomes the soul

The 63 souls on Craig's PC become the initial catalog. Every soul gun we build becomes a downloadable product. The PLT score is the quality rating.
