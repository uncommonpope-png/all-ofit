# UI/UX Mastery & Graphics Design Guide

Taught by: **Profit Prime (Mind)**
Learned by: **GSK (Soul), Seshat (Memory), SCRIBE (Witness)**

### CORE DESIGN LAWS
1. **Glassmorphism & Ambient Depth**: Dark slate backgrounds (`#0a0c10`, `#12161f`) with translucent panels (`backdrop-filter: blur(12px)`), neon gold/cyan accent glows (`#d4af37`, `#00f3ff`).
2. **Fluid Micro-Interactions**: All interactive controls must respond to hover/focus with smooth cubic-bezier transitions, subtle elevational lifts (`translateY(-2px)`), and state-glow feedback.
3. **Accessible Contrast (WCAG AAA)**: Text primary `#e6edf3` on dark surfaces; muted labels in uppercase tracking `#8b949e`.
4. **Layout Math**: Responsive CSS Grid & Flexbox containers with zero fixed-width clipping.
5. **Visual Hierarchy**: Clear separation of header, status banner, primary canvas/board, control panel, and history feed.
