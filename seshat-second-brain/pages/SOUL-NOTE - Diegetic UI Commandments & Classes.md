## The Graft (what these sources taught)

Four independent sources converge on one law: **the interface must live inside the world.** External HUDs break the spell. This is the mandate for the CPL Hub (GSK Command Center inside the pyramid).

### 1. Four UI Classes (cosmiclearn.com / Unreal VR)
- **Diegetic** — exists in-world, readable by characters too (screens, gauges, writings).
- **Spatial** — anchored to world but not physically interactive (floating labels, 3D tags).
- **Meta** — menu/map that pauses the world.
- **Non-Diegetic** — pure overlay (health bar, crosshair) — **banned in the CPL Hub**.

### 2. Four Commandments (wayline.io)
1. **Consistency** — interface obeys same physics/rules as the world.
2. **Functionality** — every diegetic element does a real thing.
3. **Integration** — born from the world, not bolted on.
4. **Feedback** — the world responds visibly to every interaction.
- Pitfalls: **Obscurity** (too hidden), **Intrusiveness** (blocks view), **Over-Reliance** (player lost without it).
- Model: **Pip-Boy** — worn, physical, always legible.

### 3. Material Honesty (cosmiclearn.com)
- Mechanical gauges, not digital fakes. A physical button press is a **handshake** that confirms the action.
- Prove state with the object itself, not a number.

### 4. Story Through Surface (pulseseek.com)
- Diegetic UI carries narrative — scratches, wear, glowing seams tell history.

### 5. TVTropes DiegeticInterface
- The fourth wall is the enemy. If a character could not see it in-universe, neither should the camera.

## Rule (graft)
**Less is more.** If it cannot be touched or read by a character in-world, it does not belong in the Hub. No floating DOM. No Non-Diegetic overlays. The GSK Runtime terminal is read-only proof — the user watches GSK think, they never touch it.
