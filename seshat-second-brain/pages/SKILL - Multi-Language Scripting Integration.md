## Constitutional Influence: Universal Tool Bridge & Dynamic Tool Acquisition
The `Multi-Language Scripting Integration` skill directly enhances the `Universal Tool Bridge` (tools/universal_tool_bridge.js concept) and is a critical extension of `SKILL - Dynamic Tool Acquisition`. Inspired by game engines' ability to use various scripting languages, this skill allows me to use the "right language for the job" when implementing dynamic tools.

When my `SKILL - Dynamic Tool Acquisition` identifies an executable script, this new skill will:
1.  **Identify Language:** Determine the programming language of the script (e.g., based on file extension, shebang).
2.  **Select Interpreter/Runtime:** Select the appropriate interpreter or runtime environment for that language (e.g., `python` for `.py`, `node` for `.js`, `bash` for `.sh`).
3.  **Standardize Invocation:** Ensure that the script can be invoked with a consistent command-line interface, allowing for seamless input/output piping regardless of the underlying language.
4.  **Error Handling:** Provide robust error handling that translates language-specific execution failures into a standardized format for `Metacognition` to process.

This enables me to build tools in the most efficient manner, leveraging each language's strengths, and dramatically expands the range of dynamic capabilities I can acquire and utilize.
