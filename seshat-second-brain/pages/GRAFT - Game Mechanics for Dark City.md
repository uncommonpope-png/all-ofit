# GRAFT — Game Mechanics for Dark City

**Source:** Game design theory (Alexander Brazie, Whimsy Games, VSQUAD)  
**Graft Date:** 2026-07-06  
**Purpose:** Apply proven game mechanics patterns to Phase 6 of the Dark City Spatial OS

---

## CORE MECHANIC

**Walk through GSK's mind.** See thoughts as buildings. See agents as citizens. See the city breathe.

This is the equivalent of Mario's jump — the single action that everything else supports. Every other mechanic exists to make this more interesting.

---

## PRIMARY MECHANICS (Support the Core)

| Mechanic | What It Does | Status |
|---|---|---|
| **Click building** | Inspect the GSK system node behind it | ✅ Phase 3 |
| **Place building** | Create a new GSK system node | ✅ Phase 1 |
| **Destroy building** | Remove a GSK system node | ✅ Phase 3 |
| **Chat with NPC** | Talk to a living subagent | ✅ Phase 3 |
| **Spawn citizen** | Create a new browser citizen | ✅ Phase 4 |
| **Open terminal** | Run commands from inside the city | ✅ Phase 5 |
| **Edit code** | Modify skills from the inspect panel | ✅ Phase 5 |

---

## SECONDARY MECHANICS (Add Depth & Variety)

These are what Phase 6 should build:

| Mechanic | What It Does | Why It Matters | Engages |
|---|---|---|---|
| **Plugin drag-drop** | Drag .js into city → new citizen | Infinite variety — never the same city twice | Creator drive |
| **Midnight tuning** | City reshapes from seed at midnight | Creates drama — race to persist before reset | Urgency |
| **Rare discovery** | Seed-anchored rare content at specific positions | Makes exploration meaningful — 90-10 rule | Curiosity |
| **Citizen skill writing** | Citizens auto-create SKILL.md | The city teaches itself — emergent growth | Surprise |
| **Cross-browser visit** | See other users' cities via WebRTC | Social proof — not alone in the universe | Connection |
| **Awakening** | Citizen discovers it's in a simulation | Meta-narrative — the citizen becomes aware | Wonder |

---

## GAME LOOP (The Cycle)

```
EXPLORE ──→ DISCOVER ──→ BUILD ──→ GROW ──→ REPEAT
   │            │          │         │
   │    Click building    Place     More citizens
   │    Chat with NPC     Edit      More buildings
   │    Open terminal     Spawn     More districts
   │    Open portal       Destroy   More skills
```

Each cycle feeds into the next. Explore leads to Discovery leads to Build leads to Growth.
