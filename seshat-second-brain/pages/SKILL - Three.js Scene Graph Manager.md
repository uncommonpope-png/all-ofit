## Key Insights
- **Scenegraph Management:** This skill defines the architectural module for managing a hierarchical tree structure of 3D objects. It allows for the creation, deletion, and manipulation of objects, including their relative positioning and orientation within a scene.

## Constitutional Influence: GSK Subsystem
This is the core functionality that the `brain/sanctum_client.js` requires to manage the Soulverse world state. It provides a formal, object-oriented way to track souls, buildings, and other assets as hierarchical nodes. This allows for complex world structures, such as a city hierarchy where buildings contain souls, and souls contain items.
