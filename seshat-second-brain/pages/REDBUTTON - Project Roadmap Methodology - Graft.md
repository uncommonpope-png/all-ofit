## Core Methodology
Standard 5-step project roadmap creation process:

1. **Break down scope** — identify all tasks, deliverables, quality standards
2. **Make a schedule** — phases with start/end dates on a timeline
3. **Link dependencies** — FS, SF, FF, SS relationships between tasks
4. **Allocate resources** — assign people, track costs, manage workload
5. **Set milestones** — diamond markers for key achievements

## Application to GSK Core Mapping
This methodology should structure the GSK core mapping effort:
- **Scope**: Every module, file, port, and connection in the GSK ecosystem
- **Phases**: Logical groupings (Core Self, Memory, Consciousness, Bridge, Security)
- **Dependencies**: What depends on what (e.g., SCRIBE bridge depends on kernel_sync)
- **Milestones**: E1 complete, boot test passes, integration test passes
