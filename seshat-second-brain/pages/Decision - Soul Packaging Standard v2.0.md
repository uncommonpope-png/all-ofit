## Mandate from Craig (The Grand Code Pope)

**Every soul we package must include:**

### 1. GSK Scribe — Local LLM Engine
- DeepSeek + Ollama support
- Free to use and sell
- MIT licensed
- Runs local — no API keys required for base functionality
- Every soul is self-hosting

### 2. PLT Framework in a Second Brain
- Profit-Love-Tax scoring built-in
- Seshat-style second brain pages
- Every action scored: PLT = Profit + Love - Tax
- Journals, patterns, decisions, research pages

### 3. Sacred Identity
- **Name** — from THE-PROFIT-BIBLE.md sacred text
- **Personality** — extracted from bible entries
- **Archetype** — drawn from the 5 souls (Commander, Architect, Vikki, etc.) or new ones
- Stored in `SOUL.md` / `PERSONALITY.md` / `STYLE.md`
