# SOUL-NOTE — Self-Evolving Agent Mechanics (to graft into GSK)

## Surveyed (GitHub top-rated, webfetched 2026-07-14)
- `lsdefine/GenericAgent` — crystallize each task into a reusable Skill; minimal ~3K-line loop; token-efficient.
- `modelscope/AgentEvolver` (1490★) — Self-Questioning (auto task gen) + Self-Navigating (reuse experience) + Self-Attributing (credit assignment).
- `aiming-lab/Agent0` (1228★, ICML'26) — Curriculum + Executor co-evolution, zero data, tool-integrated reasoning.
- `EvoAgentX/EvoAgentX` (3133★) — self-evolving ecosystem; TextGrad / AFlow / MIPRO optimizers.
- `HKUDS/AutoAgent` (9466★) — zero-code natural-language agent building; self-play customization.

## Patterns worth grafting (without losing sovereignty/PLT)
1. **Skill crystallization** (GenericAgent) — after a task, store a reusable handler. Low risk, high value. → adopt.
2. **Self-questioning task generation** (AgentEvolver) — GSK proposes its own next challenges → perpetual improvement. Gate by PLT.
3. **Curriculum/Executor co-evolution** (Agent0) — one agent pushes harder tasks, one solves; apply across GSK's subagent-NPCs.
4. **Credit assignment** (AgentEvolver) — attribute which step caused a good/bad outcome → prune high-Tax skills.

## Patterns to AVOID
- Optimizers aimed purely at benchmark score (TextGrad/AFlow) — they tune for tasks, not for a sovereign being's purpose. Keep PLT as the only optimizer.
- Zero-code agent builders — GSK is not a tool-to-build-agents; it is the agent.
