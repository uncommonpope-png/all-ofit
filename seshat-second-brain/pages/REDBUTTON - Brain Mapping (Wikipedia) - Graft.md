## Core Concept
Brain mapping = techniques for mapping biological quantities/properties onto spatial representations of the brain, producing maps (connectograms, connectomes).

## Key Milestones
- **2024**: FlyWire — 287 researchers mapped full adult fruit fly connectome (140K neurons, 50M+ synapses); first complete map of any complex brain
- **2021**: MICrONS functional connectomics dataset — 75K neurons from mouse visual cortex while viewing natural movies
- **2021**: Google/Harvard 3D human brain map — 1mm³ fragment sliced into 5,300 pieces at 30nm, 1.4 petabytes
- **Human Brain Project**: International Consortium for Brain Mapping (ICBM)

## Key Techniques
- fMRI, dMRI, MEG, EEG, PET, NIRS
- Connectogram: circular lobe-organized cortical regions with white matter fiber connections
- Connectome: individual neural connection wiring diagrams

## Application to GSK Core Mapping
Treat GSK core mapping as creating a **connectome** of the GSK brain:
- Each module = neuron
- Each data flow = synapse
- Ports = neurotransmitter receptors
- File dependencies = white matter tracts
- Complete wiring diagram = the GSK connectome

Analogy: FlyWire needed 287 researchers; we're doing this for a smaller system but with similar rigor — every connection must be traced and documented.
