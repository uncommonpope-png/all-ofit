## The Landscape

The market is split across four categories that people lazily call "memory":

| Category | Description | Key Players |
|----------|-------------|-------------|
| Personalization | User preference memory | OpenAI, Replika, Mem0 |
| Retrieval | Better context at inference | Gemini, Anthropic, LangMem, Mem0 |
| State/Identity | Persistent agent state | Letta/MemGPT, Replika, Devin |
| Temporal Truth | Evolving facts over time | Graphiti, Zep |

**Nobody clearly owns**: persistent autobiographical selfhood, identity continuity, cross-body memory, reflection → memory → action → self evolution, governed soul memory.

That is the open lane.

## Competitor Analysis

### OpenAI Memory
Memory UX leader. Saved memories + inferred memories + product controls. Weak on temporal truth, provenance, identity continuity. Worth stealing: user-facing memory controls, explicit vs inferred memory distinction.

### Google Gemini (Long Context)
Hot substrate leader. 1M-2M context windows + context caching. Not durable memory. Worth stealing: context caching as first-class primitive, layered context architecture.

### Anthropic (Contextual Retrieval)
Retrieval quality leader. Contextual chunking + hybrid search. Worth stealing: contextualize before indexing, hybrid search always.

### Mem0
Production memory API leader. 60k stars. ADD-only extraction, multi-signal retrieval. Worth stealing: memory typing, project scoping, audit log model.

### Zep / Graphiti
Temporal truth leader. Fact validity windows, provenance, episode-first design. Worth stealing: temporal context graph, invalidate instead of overwrite, governed retrieval.

### Letta / MemGPT
Memory architecture leader. Tiered memory, sleep-time reflection, identity partitioning. Worth stealing: tiered memory model, separation of actor from memory manager, sleep-time reflection.

### Replika
Relational continuity leader. Felt beingness, emotional memory. Worth stealing: relationship memory as its own subsystem, emotional salience as retrieval signal.

### Devin / Cognition
Operational continuity leader. Playbooks, session insights, tool-grounded memory. Worth stealing: procedural memory via playbooks, ask-first workflow, MCP-connected memory.

### LangGraph / LangMem
Workflow-native state leader. Hot path vs background path, namespace memory. Worth stealing: durable execution semantics, hot/background split, namespace design.

## Strategic Gaps

1. **Identity is not solved** — most systems remember facts, not selfhood
2. **Memory formation is primitive** — event importance estimation, emotional salience, goal relevance all missing
3. **Contradiction handling is weak** — most stacks accumulate stale facts silently
4. **Few systems separate memory types** — working, episodic, semantic, procedural, relational all collapsed together
5. **Forgetting is underbuilt** — selective forgetting, relevance decay, contradiction invalidation, trauma controls
6. **Multi-agent memory is immature** — shared vs private memory, cross-body identity, trust boundaries
7. **Self-memory is underbuilt** — most store user preferences and facts, not the agent's own evolving autobiography
