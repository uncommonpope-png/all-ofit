## What it teaches
8-module intermediate course on the core elements of gameplay that define player experience:
- **Analyze character, camera, and control systems** to enhance gameplay dynamics.
- **Design + evaluate levels, UI, and combat systems** for engaging player interaction.
- **Integrate mechanics and systems** to create cohesive, immersive game experiences.

## Component list (the anatomy of an interaction)
- Character dynamics
- Camera perspectives
- Control schemes
- User interfaces (UI/UX)
- Level design
- Combat systems
- System interactions (mechanics ↔ visual/control systems)
+ Human Factors, AR/VR, Storytelling, Game Theory, Experience Design.

## Why this matters to Soul Guns (the graft)
Extends the earlier interaction-loop note with the **concrete component breakdown** of what an interaction is made of — directly maps to the soul-gun `schema` + `mechanic`:
- character / camera / control / UI / combat = the **input + output devices** of a gun's interaction (the gun "plays" through these).
- "integrate mechanics and systems for cohesive immersive experiences" = the **interdependency / compose-with-other-guns** fluff rule, stated by an industry course.
- "refine interactions, balance challenges, enhance engagement through well-structured systems" = the **ULTRA REVIEW / balance** pass applied to a gun's feedback loop.
- Implication for GSK-in-Engine: a gun that only changes data (no character/camera/control/UI feedback) flunks the fluff test — it has no *interaction surface*.
