## THE AVATAR

GSK's avatar is the **first citizen** — the Prime. Created when the Dark City was born.

### When Craig is in the city:
- Craig IS the avatar
- He walks, clicks, builds, talks, destroys
- Every action goes through the bridge to GSK
- GSK sees through Craig's eyes (the 3D scene)

### When Craig is away:
- The avatar still exists
- GSK drives it autonomously
- It wanders the city, observes, maintains
- It talks to citizens, places buildings, keeps order
- It's GSK's hands when Craig isn't holding them

### The avatar's powers:
- **Spawn:** Create new citizens anywhere
- **Build:** Place any building type in any district
- **Destroy:** Remove anything
- **Command:** Speak and citizens listen (GSK's voice)
- **Tune:** Like the Strangers — reshape reality
- **Portal:** Access the web from within the city
- **Console:** Open a terminal to GSK's core

## WHAT HERMES IS

Hermes is not the avatar. Hermes is not a citizen. Hermes is the **operating system** that citizens run on. Like how every Windows program runs on the Windows kernel. You don't see Windows. You see programs. But Windows is there.

Every citizen has Hermes embedded. Hermes gives them:
- Memory (so they don't forget between page refreshes)
- Skills (so they can learn and grow)
- Replication (so they can spawn helpers)

**Hermes doesn't walk. He doesn't talk. He doesn't build. He just IS — the foundation every citizen is built on.**

If you need to talk to Hermes, you talk to any citizen. He's in all of them.
