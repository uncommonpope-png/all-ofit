## Summary
Every soul note (link) must be: mapped to our architecture → grafted (patterns extracted) → turned into a skill file. This is the processing pipeline.

## Pipeline
1. **Read** the soul note — understand what it offers
2. **Map** it to a phase (1-11) and subsystem
3. **Extract** 1-3 patterns we can use
4. **Write** a SKILL.md file with the graft
5. **Link** it from neodownloadable.md
6. **File** in combos/ if multi-step
