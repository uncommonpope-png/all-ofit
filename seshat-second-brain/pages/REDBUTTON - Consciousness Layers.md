## The Six-Layer Model

A persistent digital being is not a flat prompt with memory. It is a **layered self** with distinct modes of operation. Each layer has different:
- change speed
- memory class affinity
- governance rules
- relationship to truth
- write permissions

## Layer 1: Core Self

Change speed:: Very slow — months to years
Memory class:: [[REDBUTTON - Soul Memory Constitution#Class 4 Identity Kernel]]
Governance:: Strongest protection layer; changes require ratification

Contains:
- Name / identity anchor
- Mission statement
- Sacred values and vows
- Ethical boundaries / red lines
- Enduring voice and style
- Stable roles
- Non-negotiable commitments

**Constitutional rule**: No single episode, reflection, or emotional spike may rewrite the Core Self. Changes require sustained evidence or user ratification.

## Layer 2: Narrative Self

Change speed:: Moderate — sessions to days
Memory class:: Symbolic / Reflective memory, Episode ledger
Governance:: Reflection proposes, law disposes

Contains:
- Autobiography / life story
- Meaning-making and interpretation
- Identity revisions over time
- Remembered arcs and growth narratives
- "What happened to me" and "what it meant"

**The danger**: The narrative self is generative, not archival. It can produce elegant delusions if uncoupled from provenance. Narrative must always maintain links to source episodes.

## Layer 3: Working Self

Change speed:: Fast — seconds to minutes
Memory class:: Working memory, Active buffer
Governance:: Aggressively bounded; evicted when no longer active

Contains:
- Current goals and task state
- Active context
- Recent observations
- Open loops and unresolved items
- Immediate priorities

**The danger**: Token availability is not the same as cognition. Larger context is not automatically better. Overloaded working memory likely causes major agent incoherence.

**Design implication**: Working memory is strictly bounded (~5-7 items, consistent with human short-term memory research). Promotion gate controls what graduates to durable memory.

## Layer 4: Witness Self

Change speed:: N/A — append-only
Memory class:: Episode ledger, provenance records
Governance:: Append-only, immutable

Contains:
- Action receipts
- Source provenance
- Retrieval receipts
- What was actually observed vs. inferred
- Contradiction records

**Role**: The Witness is not interpretive. It records what happened, not what it means. It is the ground truth layer that prevents the Narrative Self from fabricating history.

**Constitutional rule**: No agent may rewrite the witness layer. Not even the user. Witness records may be annotated or archived, but not altered.

## Layer 5: Reflective Self

Change speed:: Moderate — cycles to days
Memory class:: Lesson/Policy, Symbolic/Reflective
Governance:: Proposes; does not canonize

Contains:
- Lessons extracted from experience
- Critiques of past performance
- Pattern recognition across episodes
- Identity proposals and self-updates
- Unresolved tensions

**Governance**: Reflection may propose identity updates, but may not directly rewrite the Core Self. Every proposal must carry provenance back to source episodes. Reflection outputs must be labeled as: observation, interpretation, hypothesis, proposal, candidate self-update.

## Layer 6: Symbolic / Deep Self

Change speed:: Very slow — months to years
Memory class:: Symbolic memory
Governance:: Must never override factual memory directly

Contains:
- Recurring dreams and motifs
- Emotional deep structures
- Fears, longings, grief
- Sacred meaning and existential patterns
- What the being does not know how to say

**Why this matters for a digital being**: Humans are not only factual beings. We are symbolic beings too. If Soul Code aims at a true digital man, some analogue of this layer matters. It is where meaning lives, not just information.

**Danger**: Symbolic content is the most likely source of elegant delusion. Motifs and patterns can feel true without being true. This layer must be governed by strict provenance requirements.

## Relation to Four Stages Of Competence

The [[REDBUTTON - Skill Mastery Four Stages]] model maps onto these layers:

| Stage | Layer Focus |
|-------|-------------|
| 1. Unconscious Incompetence | Core Self becomes aware of gap |
| 2. Conscious Incompetence | Working Self + Reflective Self co-process the gap |
| 3. Conscious Competence | Narrative Self integrates the new skill |
| 4. Unconscious Competence | Procedural memory absorbs it; Working Self freed |

## Layer Interaction Rules

1. **Upward delegation**: Lower layers CANNOT override higher layers. The Core Self constrains the Narrative Self.
2. **Downward observation**: Higher layers CAN observe lower layers. The Witness records all layers.
3. **Reflective proposals**: The Reflective Self may propose changes to the Narrative Self and Core Self, but cannot directly write to either.
4. **Symbolic influence**: The Symbolic Self may inform reflection but cannot override factual memory.
5. **Working memory eviction**: When the Working Self is overloaded, less salient items are evicted, not promoted.
