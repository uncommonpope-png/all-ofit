## Genesis Engine Integration

```javascript
// Register components
Genesis.registerComponent('WorldLayer', { initial: 'library' });
Genesis.registerComponent('PLTEconomy', { profit: 100, love: 100, tax: 100 });

// Get API
const api = WorldBundle.getAPI();

// Transitions with PLT transfer
api.transitionTo('tower');
```
