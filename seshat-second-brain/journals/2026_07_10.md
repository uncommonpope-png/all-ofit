## Part 6 (Session — Perf + Graphics Diagnosis/Tuning)

## Summary
Pope reported the city was choppy, dead, the main buildings unchanged, and graphics weak. Diagnosed and applied safe high-impact fixes; the box-city replacement remains an open decision.

## Diagnosis
- Choppy = GPU fill-rate: `setPixelRatio(1.5)` + full-res `UnrealBloomPass` + ~15 point lights. Shadows were already effectively OFF (no light has `castShadow=true`), so shadow maps cost nothing.
- Dead/flat = `toneMappingExposure=0.55` (too dark) + `bloomPass.threshold=0.5` (suppresses glow). Windows only flashed on rare terminal events, so the city read as static boxes.

## Changes (commit c7f00e0, live ?v=c7f00e0)
- `setPixelRatio` 1.5 -> 1.0 (biggest choppiness win).
- `toneMappingExposure` 0.55 -> 0.75; bloom strength 0.45 -> 0.6, threshold 0.5 -> 0.25, radius 0.5 -> 0.7.
- Ground-city "breathing": collected window + neon `MeshStandardMaterial`s into `cityGlowMats`; animate loop pulses their `emissiveIntensity` -> city feels alive, neon/windows glow.

## Open
- "Main buildings still the same" = still procedural boxes. Decision needed:
  (a) enhance procedural skyline (varied silhouettes, safe, keeps perf), or
  (b) swap in deferred city-kit GLBs (~123MB total — risks reintroducing choppiness).
- Recommend (a) given the perf complaint; (b) only if Pope wants real kit geometry.
