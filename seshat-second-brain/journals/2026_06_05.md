## Key Takeaways for Soul Dashboard

1. **Animation:** Replace ad-hoc animations with `Motion` (hybrid engine, 120fps) or `react-spring` (spring-physics)
2. **Data Viz:** Swap 3D Knowledge Graph with `G6` (graph engine) or `Semiotic` (MCP server for AI)
3. **Design-to-Code:** Use `Open Design` skills pattern for agent-native design generation
4. **3D Tools:** `r3f-mcp` would let Claude inspect/modify our R3F scene live — game changer for dashboard dev
5. **Icons:** Replace any hardcoded SVGs with `Lucide` or `Phosphor` (tree-shakable, MIT)
6. **Design Tokens:** `FORGE` can generate a full token system from our brand color in 30 seconds
7. **Quality:** `OPTIK` gives a 0-100 design score — we should benchmark the dashboard
