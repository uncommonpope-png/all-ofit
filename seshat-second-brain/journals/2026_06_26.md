# Session 8 — June 26, 2026 — Shopify Blog Agent Image Upload Pipeline

## What Was Done

### Phase 1: GraphQL Image Upload Pipeline
- **Problem:** REST `staged_uploads.json` endpoint returned HTTP 406 Not Acceptable for the store
- **Solution:** Full GraphQL pipeline built:
  1. `stagedUploadsCreate` mutation → returns signed Google Storage URL + resourceUrl
  2. `PUT` file bytes directly to signed URL (no FormData needed)
  3. `fileCreate` mutation using `originalSource: resourceUrl` → creates MediaImage
  4. Poll `node(id: fileId)` every 1.5s until `fileStatus: READY` → CDN URL available
- `_uploadImage` renamed to `_uploadImageGraphql` using `https` module (no external deps)

### Phase 2: ChatGPT Image Integration into Blog Posts
- `_pickChatgptImage()` refactored to use `ImagePool.getImages()` public API
- Prefers unused ChatGPT images, falls back to any ChatGPT image if all used
- Image uploaded to Shopify CDN → embedded as hero `<img>` at top of article
- Image marked as used via `_markUsed(filepath, 'shopify-blog', 'shopify')`

### Phase 3: Bulk Publication
- 10 articles published with ChatGPT hero images (1 test + 5 bulk + 4 bulk)
- Blog count: 9 → 19 articles
- ChatGPT images used: 36 (from 76 total, 40 unused remaining)
- All articles verified: `node --check` passes; GraphQL confirms `<img>` tag in body

## Key Decisions
- **GraphQL over REST** — `stagedUploadsCreate` + `fileCreate` works; `staged_uploads.json` returns 406
- **fileSize as string** — Shopify 2024-10 requires `UnsignedInt64` as string
- **1.5s polling** — image URL typically available on first poll (fileStatus transitions UPLOADED → READY instantly)
- **Prefer unused ChatGPT images** — rotate through pool before reusing

## Relevant Files
- `lib/shopify-blog.js` — MODIFIED: `_uploadImageGraphql()` (new pipeline), `_pickChatgptImage()` (refactored), `cycle()` (image upload + embed)
